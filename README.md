# [ParkSmart](ENGI 9867 and 9874 Project) 


![Image](./frontend/src/assets/images/Parksmart%20Dashboard.png)
ENGI 9874: Software Design and Verification
Topic: Model-Driven Architecture and UML-Based Design of a Vehicle Parking Management System


Summary:
We will design the Vehicle Parking Management System using Model-Driven Architecture (MDA) principles combined with UML modeling, utilizing free tools such as Papyrus or Modelio. Our focus will be on modeling system components, their interactions, and workflows through UML diagrams, applying software design principles like layered architecture and MVC. The project will include a small-scale prototype implementation aligned with our design models.


ENGI 9839: Software Verification and Validation
Topic: Formal Specification and Verification of Vehicle Parking Management System Using Alloy


Summary:
We will formally specify the Vehicle Parking Management System using the Alloy modeling language to define critical constraints and rules such as reservation conflicts and payment validation. Using Alloy’s analyzer, we will verify system properties and illustrate how formal methods enhance software correctness and reliability.
